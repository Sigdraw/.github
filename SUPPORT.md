# Getting help

## Open-source projects

For questions about using Redstone, Rainglass, or any other Sigdraw open-source
project, start with the repository's README and documentation. If that does not
answer your question, open a discussion (where enabled) or an issue on that
repository.

Before opening an issue, search existing issues and discussions to see whether
your question has already been answered.

## The Sigdraw app

The Sigdraw IDE is closed source and is not supported through GitHub.

- Documentation: [sigdraw.com/docs](https://www.sigdraw.com/docs)
- Bug reports and feature requests:
  [sigdraw.com/feedback](https://www.sigdraw.com/feedback)

## Security

To report a security vulnerability, follow the [security policy](SECURITY.md).
Do not open a public issue.

## Everything else

For anything else, email [hello@sigdraw.com](mailto:hello@sigdraw.com) or use
the [contact page](https://www.sigdraw.com/contact).
